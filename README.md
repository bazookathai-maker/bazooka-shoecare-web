# BAZOOKA — Premium Sneaker Care

เว็บไซต์แบรนด์ BAZOOKA สำหรับสินค้า sneaker care สไตล์ Clean · Premium · Modern · Minimal

## Tech Stack

- React 19
- Vite 8
- React Router

## Getting Started

```bash
npm install
npm run dev
```

เปิด [http://localhost:5173](http://localhost:5173)

## Pages

| Route | Description |
|-------|-------------|
| `/` | หน้าแรก — Hero, สินค้า 3 ตัว, About Brand, Footer |
| `/products` | สินค้าทั้งหมด 27 รายการ (Grid 4 คอลัมน์ desktop / 2 คอลัมน์ mobile) |

## Build

```bash
npm run build
npm run preview
```

## Color Palette

- White `#FAFAFA`
- Blue-gray `#5A6B7D` / `#3D4F5F`
- Muted green `#6B7F6E`
